# shukan-app

## 1. プロジェクト概要

`shukan-app` は、シンプルながらデザインにこだわった **習慣管理 Web アプリ** です。ユーザーは「今日の目標」（例: "筋トレ10分"）を設定し、完了ボタンをクリックするだけで達成を記録できます。達成時にはカラフルな confetti アニメーションとバナーが表示され、継続日数（ストリーク）や月間カレンダーで過去の実績を一目で確認できるため、モチベーションを高めながら習慣を定着させることができます。

---

## 2. 主な機能

- **目標設定 UI**：右上の歯車アイコンからモーダルを開き、自由に目標テキストを編集可能。
- **完了ボタン**：クリックで色がグレーからプレミアムオレンジへ変化し、テキストが "達成済み！" に変わります。
- **祝福エフェクト**：`canvas-confetti` を用いた華やかな紙吹雪と、アニメーションバナーが表示されます。
- **ストリーク表示**：現在の連続達成日数をカード上部にリアルタイムでカウント。
- **月間カレンダー**：当月のカレンダーに達成日をマークし、今日の日付もハイライト。
- **リセット機能**：左下の "ステータスをリセット" ボタンでローカルストレージをクリアし、デモやテストが簡単に実施可能。
- **設定モーダル**：目標テキストや UI カラーを即座に変更できるインタラクティブな設定画面。
- **ローカルストレージ永続化**：ページリロード後も達成データが保持されます。
- **レスポンシブデザイン**：モバイルでも快適に操作できるレイアウト。

## 4. ローカルでの起動方法・使い方例

### 開発サーバー起動
```bash
npm run dev
```
上記コマンド実行後、デフォルトで `http://localhost:5173` がブラウザで開かれます。ページが表示されたら以下の操作を試してください。

1. **目標設定**：右上の歯車アイコン → モーダル → テキスト入力 → 保存
2. **達成**："完了" ボタンをクリック → ボタンがオレンジに変化し、"達成済み！" バナーが表示されます
3. **ストリーク確認**：カード上部に現在の連続達成日数がリアルタイムで更新されます
4. **カレンダー確認**：当月のカレンダーで達成日がハイライト（星アイコン）され、今日の日付も強調表示されます
5. **リセット**（デモ向け）：「ステータスをリセット」ボタンでローカルストレージを削除し、初期状態に戻ります

### 本番ビルド（任意）
```bash
npm run build   # `dist/` ディレクトリに最適化された静的ファイルが出力されます
```
ビルド後は、任意の静的サーバ（例: `serve -s dist`）でホスティングできます。
